Hangulが保存した行の情報に従うので、ページや改行がずれません。元のフォントがないMacでも、改行は元のフォントの字幅どおりです。

できること

4種類のファイル、ひとつの使い方

文書・表計算・スライド・PDFがタブで並んで開きます。メニューもショートカットも、コマンド検索 ⌘K も、AIを呼ぶ場所も、どのファイルでも同じです。

文書 · HangulとWord

表、画像、脚注と文末脚注、ヘッダーとフッター、ページ番号、目次、メモ、数式まで。スペルチェック、文書の比較、個人情報の墨消し、差し込み印刷もできます。

表計算 · Excel

420以上の関数、条件付き書式、フィルター、ピボット、グラフ。古い .xls やCSVも開けます。シートの値を文書やスライドにつないでおけば、一緒に更新されます。

スライド · PowerPoint

テーマ、アニメーション、画面切り替え、発表者ビュー。文書の見出しと本文から、そのままスライドを作れます。

PDF

読む、注釈をつける、フォームに入力する、文字や画像を直す。ページの削除・回転・結合もでき、必要なら編集できる文書に変換します。

フォント

見た目を確かめながらフォントを選び、名前で探せます。ナヌムゴシック、ナヌム明朝、Pretendard、ソンミョンを同梱。フォントファイルをウインドウにドロップすれば、すぐ使えます。

AIアシスタント

自分のClaudeのキー、またはMac上のモデル（Ollama）で、文書を読んだり直したりできます。提案を確かめて適用するまで何も変わらず、元に戻すのも一度で済みます。

AIエージェント

AIが扱いやすいように作りました

アプリの中に、ウインドウなしで動くコマンドラインとMCPサーバーが入っています。Claude CodeやClaude DesktopなどのエージェントがHangul・Word・Excel・PowerPointのファイルを構造で読み、変えるところだけを命令で直し、アプリと同じやり方で保存します。

1行でつなぐ

アプリの Tools › Connect AI (MCP) からコマンドをコピーして貼り付けるだけ。ほかに入れるものはありません。

トークンを節約する順番

まず構造、次に必要な範囲だけを読み、変えるところだけを命令で送って保存。書式は読みも送りもしません。

ない機能も作って使う

コマンドを組み合わせれば、たくさんのファイルをまとめて直したり、文書の表を集めてシートに移したりと、アプリにない仕事もAIが組み立ててこなします。

壊れにくい

プレビューと適用は別々。元のファイルに上書きするときは .bak を残します。文書がMacの外に出ることはありません。

例 · 10ページの報告書で表のセルを2つ直すトークン
office_outline 報告書.hwp見出し12 · 表3 · 空欄5≈ 300
office_table t0.3.0表をひとつだけ · 6行 × 4列≈ 180
office_apply set_cell ×22セルを修正 · 書式はそのまま≈ 90
office_save保存 · .bak を残す≈ 20
合計≈ 600

ファイルを丸ごと読んで書き直すと、1万トークンを軽く超えます。

claude mcp add hyperseven -- "/Applications/HyperSeven Office.app/Contents/Resources/cli/hyperseven" mcp

コマンドライン：hyperseven outline 報告書.hwp · hyperseven convert 報告書.hwp 報告書.docx · hyperseven apply 報告書.hwp 命令.json -o 結果.hwp。詳しくはマニュアル（英語）と llms.txt へ。

新しいバージョンが出ると、アプリがお知らせします。アプリケーションフォルダのアプリを入れ替えても、文書と設定はそのままです。

はじめての起動

  1. .dmg を開き、HyperSeven Office をアプリケーションフォルダにドラッグします。
  2. 最初の起動では「開発元が未確認」という警告が出ます。まだAppleの公証を受けていないためです。
  3. アプリケーションフォルダでアプリを右クリック → 開く → 開く。一度だけで大丈夫です。
  4. macOS 15以降は、システム設定 → プライバシーとセキュリティの一番下にあるこのまま開くを押します。

それでも開かない場合は、ターミナルで xattr -cr "/Applications/HyperSeven Office.app" を一度実行してください。ダウンロードしたファイルに付く「隔離」の印を外すだけです。

HyperSeven Officeは文書をどこにも送らず、ほかのプログラムを一緒にインストールすることもありません。

よくある質問

気になること

本当に無料ですか？

はい。すべての機能が無料で、登録・広告・支払いはありません。

HWPファイルとは？

HWPとHWPXは、韓国の官公庁・学校・企業で広く使われているワープロ「Hangul」の形式です。HyperSeven Officeなら、HangulがないMacでも開いて保存できます。

Hangulで作った文書と同じに見えますか？

ページと改行は、Hangulが保存したとおりに表示されます。フォントがない場合は似たフォントで描きますが、改行は元の字幅どおりです。ここで保存した文書はHangulでもそのまま開けます。違って見える文書があれば教えてください。

日本語で使えますか？

アプリの表示はいまのところ韓国語と英語です。Macの言語が日本語なら英語で表示され、設定（Settings）で切り替えられます。

Intel MacやWindowsでも使えますか？

いまはApple Silicon搭載Mac用です。Intel Mac版とWindows版はその次に用意します。

文書が外に送られることはありますか？

いいえ。文書も自動保存もMacの中だけです。アプリがインターネットを使うのは、新しいバージョンの確認だけ。AIアシスタントは、キーを入れてオンにしたときに、選んだ内容だけを送ります。

Hancom社の製品ですか？

いいえ。Hancom社が公開しているHWP文書ファイル形式の資料を参考に、独自に作ったプログラムです。HangulおよびHWPはHancom社の商標です。

不具合を見つけました。

Tools › Report a Problem… を選んで、ひとこと書くだけです。アプリのバージョンとエラーの記録は自動で添えられ、文書の文字は送られません。見た目の問題なら、文字を消したコピーを添えられます。直ったらアプリがお知らせします。

同梱フォントのNanum Gothic・Nanum Myeongjo（Naver）、Pretendard（キル・ヒョンジン）、Song MyungはSIL Open Font License 1.1で配布されています。HyperSeven OfficeはElectron・Chromium・pdf.jsなどのオープンソースの上に作られています。

韓国語のスペル辞書は hunspell-dict-ko 0.7.94（hunspell-dict-ko貢献者、国立国語院）で、GPL-3.0-or-laterで配布されており、改変せず別ファイルとして同梱しています。ソースは hunspell-dict-ko-0.7.94.tar.gz から入手できます。
