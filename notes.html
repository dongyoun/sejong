업데이트 내역 · 하이퍼세븐 오피스

함께 고치고 더해 온 기록

알려 주신 불편과 새로 더한 기능을 버전마다 적습니다. 새 버전이 나오면 앱이 알려 드리고, 업데이트는 언제나 무료입니다.

2.0.52026-11-09

표 계산이 한글처럼 저절로 다시 계산되고, 손에 익은 동작이 훨씬 편해졌습니다.

  • 블록 합계·계산식이 칸을 고치면 따라 바뀝니다. 워드로 저장해도 계산식이 남습니다.
  • 엑셀에서 복사한 표를 표 칸에 붙이면 칸을 채웁니다.
  • 글자 색·형광펜 팔레트, 글자 크기 −/+ 단추와 목록, 표 크기 고르기가 생겼습니다.
  • 같은 파일은 한 번만 열리고, 맥 ⌘↑·⌘↓와 목록 Tab 수준이 익숙하게 동작합니다.
  • 오류와 불편한 순간을 글 내용 없이 알려 고칩니다(환경 설정에서 끌 수 있음).

2.0.42026-11-08

그림 넣기와 크기 맞추기가 훨씬 부드러워졌습니다.

  • 크기를 바꿀 때 미리 보여 주고, 손잡이가 커졌습니다.
  • 모서리를 끌면 가로·세로 비율이 그대로 유지됩니다.
  • 그림을 누른 채 바로 끌어 옮깁니다.
  • 화면 아래에 쪽 맞춤·폭 맞춤·확대 단추가 생겼습니다.
  • 인텔 맥용과 Microsoft Store(윈도우)에서도 받습니다.

2.0.32026-11-07

맥 앱이 애플 공증을 받았습니다. 내려받아 처음 열 때도 경고 없이 바로 열립니다.

  • 맥: 처음 열 때 나오던 '확인되지 않은 개발자' 경고와 '그래도 열기' 단계가 없어졌습니다.
  • 작업 창의 문단 왼쪽·오른쪽 여백에 음수도 넣을 수 있습니다. 문단을 본문 여백 밖으로 내밀 때 씁니다(문단 모양 창과 같습니다).
  • 윈도우: 새 버전 안내 창이 윈도우에 맞는 설치 방법을 알려 줍니다.

2.0.22026-11-06

한글 문서를 워드로 저장하면 문단 사이 간격까지 한글과 같게 나옵니다.

  • 워드(.docx)로 저장한 문서를 워드에서 열 때 문단 사이가 한글보다 좁아 보이던 것을 고쳤습니다.

2.0.12026-11-06

앱이 꺼져 있을 때 문서를 두 번 눌러 열면, 그 문서가 바로 열립니다.

  • 문서를 두 번 눌러 앱을 켜면 빈 문서만 뜨던 문제를 고쳤습니다 (맥 Finder·윈도우 탐색기·명령줄 모두).

2.0.02026-11-06

HyperSeven Office로 새롭게 나왔습니다. 한글·워드·엑셀·파워포인트·PDF를 한 앱에서 다루고, 윈도우판과 영어 화면, 명령 찾기가 더해졌습니다.

  • 윈도우 10·11(64비트) 지원: .exe를 실행하면 바로 설치되고, 한글 Windows 방식 단축키를 그대로 씁니다.
  • 영어 화면: 처음에는 운영체제 언어를 따르고, 환경 설정 › 보기 › 언어에서 바꿉니다.
  • 명령 찾기 ⌘K(윈도우 Ctrl+Shift+K): 이름이나 초성 몇 자로 모든 명령을 바로 실행합니다.
  • 문제 알리기: 도구 › 문제 알리기…에서 한 줄만 적어 보내면 됩니다. 문서 모양이 문제라면 글자를 지운 사본을 붙일 수 있고, 고쳐지면 앱이 알려 드립니다.
  • 쓰던 설정·단축키·최근 문서·자동 저장은 처음 실행할 때 그대로 옮겨 옵니다. AI 도우미 열쇠만 한 번 다시 넣어 주세요.
  • AI 에이전트용 명령줄과 MCP 이름이 hyperseven, 도구 이름이 office_*로 바뀌었습니다. 도구 › AI 연결 (MCP)에서 새 명령을 복사해 다시 연결해 주세요.
  • 새 아이콘과 새 홈페이지.
