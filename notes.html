판마다 고친 것과 새로 된 것

맨 위가 가장 새 판입니다. 새 판이 나오면 앱이 알려 줍니다.

1.4.02026-11-06

옛날 파일까지 열리고, 한글에서 인쇄한 것과 더 비슷하게 나옵니다.

  • 옛 형식 파일을 엽니다. 워드 97-2003(.doc), 파워포인트 97-2003(.ppt), 서식 있는 글(.rtf), 오픈오피스·리브레오피스 문서(.odt·.ods), 글 파일(.txt·.md·.html)까지 됩니다. 고쳐서 저장하면 새 형식(DOCX·PPTX·XLSX)으로 따로 남기고 원본은 그대로 둡니다.
  • 암호를 건 .doc·.xls·.ppt 파일도 암호를 넣으면 열립니다.
  • 은행이나 관공서에서 받은 .xls 는 속이 HTML 표나 XML 인 경우가 많은데, 이런 파일도 엑셀처럼 표로 엽니다.
  • 한글 문서의 줄 간격과 다단, 단이 바뀌는 자리의 간격을 한글이 인쇄한 PDF 와 하나씩 맞춰 다시 쟀습니다. 줄 정보가 저장되지 않은 문서(다른 프로그램이나 AI 가 만든 HWPX)도 한글과 거의 같은 자리에 나옵니다.
  • 워드 문서의 쪽 나눔이 워드와 더 가까워졌습니다.
  • 정렬: 표의 줄이나 블록으로 잡은 문단을 가나다·숫자·날짜 순으로 정렬합니다 (편집 > 정렬).
  • 색인: 낱말에 표시를 달고 색인을 만듭니다 (도구 > 색인). 워드의 색인 표시도 읽고 저장합니다.
  • 그림의 밝기·대비·회색조·흑백·투명 색이 문서와 발표 모두 원본대로 나옵니다. 옛 파워포인트의 글맵시와 그러데이션도 원본에 가까워졌습니다.
  • 쪽 윤곽을 끄고 볼 수 있습니다 (보기 > 쪽 윤곽). 문서의 선택 상자와 라디오 단추는 눌러서 값을 바꿉니다.
  • 표 테두리를 마우스로 끌어 칸 너비와 줄 높이를 바꿉니다. 칸이 글보다 높을 때 빈 곳을 눌러도 그 칸으로 들어갑니다.
  • 블록으로 잡은 글을 끌어서 옮깁니다. Ctrl(맥은 Option)을 누른 채 놓으면 복사합니다. 끌어서 선택하다 화면 끝에 닿으면 저절로 스크롤합니다. 그림과 글을 다른 앱에서 끌어다 놓으면 놓은 자리에 들어갑니다.
  • PDF 로 저장하면 개요가 책갈피로 들어가고, 하이퍼링크를 누를 수 있습니다.
  • 셈터: 함수가 420여 개로 늘었습니다. 데이터베이스 함수(DSUM·DGET 등), 감가상각(DB·DDB·VDB), 행렬(MMULT·MINVERSE), 진법 바꾸기, 통계 분포(T·F·카이 제곱 등), XIRR, TEXTSPLIT, 정규식까지 됩니다.
  • 셈터: `=UNIQUE(A1:A9)` 같은 수식의 결과가 엑셀 365 처럼 옆 칸으로 넘칩니다. `A1#` 로 넘친 범위를 가리킵니다.
  • 셈터: 금액을 한글로 쓰는 표시 형식(`[DBNum4]`, "일금 일백이십삼만 원정")과 NUMBERSTRING·DATESTRING 함수가 됩니다. 셀 서식 > 기타에서 고릅니다.
  • 셈터: 데이터 메뉴에 정렬(기준 셋까지), 텍스트 나누기, 중복된 항목 제거, 데이터 유효성 검사, 이름 관리자가 생겼습니다. 인쇄 영역을 정할 수 있고, 고른 범위의 테두리를 끌어 칸을 옮깁니다.
  • 보임터: 표에 줄과 칸을 넣고 지웁니다. 슬라이드 배경색을 바꿉니다 (슬라이드 > 배경 서식).
  • 열 수 없는 파일을 열면 왜 안 되는지 알려 줍니다. 1990년대 한글 파일, 그림 파일, 다른 프로그램의 파일, 빈 파일, 손상된 파일을 구분합니다.
  • 손상된 파일 때문에 앱이 멈추거나 메모리가 넘치던 경우를 찾아 고쳤습니다.
  • 앱 이름을 세종으로 통일했습니다. 창 제목과 메뉴에서 '신워드'가 빠집니다.

1.3.02026-11-05

문서가 더 원본처럼 보이고, 도형과 차트를 직접 다룰 수 있습니다.

  • 한글 문서의 도형을 제대로 그립니다. 화살표, 곡선, 호, 연결선, 겹선, 그러데이션이 원본대로 나오고, 묶음 안에 또 묶음이 있어도 자리가 어긋나지 않습니다.
  • 글맵시, OLE 개체(저장된 미리 보기), 체크 상자 같은 양식 개체, 표 칸과 글상자의 세로쓰기가 보입니다.
  • 입력 > 도형에 화살표, 둥근 사각형, 호, 별, 말풍선 등 여러 도형이 늘었고, 개체 속성에서 화살표·선 종류·그러데이션을 고칩니다. 좌우·상하 대칭도 됩니다.
  • 입력 > 차트로 한글·워드 문서에 차트를 넣습니다. 표 안에서 부르면 그 표의 값으로 시작하고, 두 번 눌러 다시 고칩니다.
  • 워드 문서의 도형(기본 도형 90여 가지와 테마 색)·차트·SmartArt·글 워터마크가 보입니다. 줄 간격을 워드와 같은 방식으로 재어 쪽 수가 워드와 거의 같아졌습니다.
  • 워드의 변경 내용 추적: 도구 > 변경 내용에서 보기, 모두 적용, 모두 취소를 합니다.
  • HY 글꼴의 윗부분이 잘리거나 열리지 않던 문제, 한컴 전용 기호가 깨지던 문제, 옛한글 조합 글자가 벌어지던 문제를 고쳤습니다.
  • 한글 문서의 쪽 나눔과 표 위치가 한글과 더 가까워졌습니다.
  • 메일 머지 자료로 한글·워드 문서와 글 파일을 쓸 수 있습니다.
  • 암호를 건 워드·엑셀·파워포인트 파일을 열고 저장합니다.
  • 셈터: 조건부 서식과 메모를 만들고 고칩니다. 표 스타일이 보이고 `표1[금액]` 같은 구조적 참조를 계산합니다. 그림과 도형도 인쇄됩니다.
  • 보임터: 슬라이드 쇼에서 동영상과 소리를 재생합니다. 배경 그림이 원본대로 나옵니다.
  • 명령줄·MCP 로 엑셀과 파워포인트도 읽고 고칩니다.

1.2.02026-11-01

실행할 때 새 판을 확인하고, 앱을 다시 받지 않아도 기능이 고쳐집니다.

  • 세종을 켜면 홈페이지에서 새 판과 알림을 확인합니다. 보내는 것은 확인 요청 하나뿐이고, 문서나 사용 기록은 보내지 않습니다.
  • 작은 고침과 새 기능은 앱이 받아 두었다가 다시 시작할 때 적용합니다. 설치 파일을 다시 받지 않아도 됩니다.
  • 문제가 생긴 기능은 고친 판이 나올 때까지 잠시 꺼 둘 수 있게 했습니다.
  • 도움말 > 이용 정보에서 지금 쓰는 판을 봅니다. 모든 기능은 계속 무료입니다.

1.1.02026-10-29

AI 와 함께 쓰는 세종 — 명령줄과 MCP 서버.

  • 앱 안에 창 없이 돌아가는 명령줄과 MCP 서버가 들어갑니다. Claude Code·Claude Desktop 같은 AI 에이전트가 한글(HWP·HWPX)·워드 문서를 구조로 읽고, 바꿀 문단만 명령으로 고쳐, 앱과 같은 방식으로 저장합니다. 도구 > AI 연결 (MCP)에서 붙이는 명령을 복사합니다.
  • 문서를 마크다운·글·구조 JSON 으로 내보내고, hwp·hwpx·docx 를 서로 바꾸는 명령줄(sejong convert).
  • AI 도우미에서 여러 문단을 한꺼번에 넣어도 뒤 문단 주소가 밀리지 않게 했습니다.

1.0.02026-10-29

세종 1.0 — 한글·워드·PDF·엑셀·파워포인트 문서를 한 앱에서, 무료로.

  • 한글 문서(HWP·HWPX)를 한글과 같은 쪽·줄로 열고 고치고 저장합니다. 워드(DOCX)·PDF·엑셀(XLSX·CSV)·파워포인트(PPTX)도 엽니다.
  • 글꼴 상자를 새로 만들었습니다. 이 문서의 글꼴, 최근 쓴 글꼴, 한글·워드 글꼴, 이 컴퓨터의 모든 글꼴을 그 글꼴 모양으로 보여 주고 이름·초성으로 찾습니다.
  • 글꼴 추가: 글꼴 파일(.ttf·.otf)을 문서 창에 끌어다 놓거나 도구 > 글꼴 추가로 넣습니다. 도구 > 글꼴 관리에서 보고 뺍니다.
  • 나눔고딕·나눔명조·Pretendard·송명(모두 OFL 무료 글꼴)을 함께 넣었습니다. 한글 글꼴이 없는 컴퓨터에서도 비슷한 모양으로 보이고, 줄 바꿈과 쪽수는 원래 글꼴의 글자 폭대로 맞춥니다.
  • 새 버전 확인: 도움말 > 새 버전 확인. 새 판이 나오면 앱이 알려 줍니다.

한글·워드·PDF·엑셀·파워포인트 문서를 한 앱에서. 맥용, 무료.
