함께 고치고 더해 온 기록

알려 주신 불편과 새로 더한 기능을 버전마다 적습니다. 새 버전이 나오면 앱이 알려 드리고, 업데이트는 언제나 무료입니다.

3.4.52026-11-13

Enter 처리를 다듬었습니다.

  • 표 칸과 문단에서 Enter 를 누른 만큼 정확히 줄이 바뀝니다.

3.4.42026-11-13

하이퍼 AI와 응원하기 화면이 간결해졌습니다.

  • 꼭 필요한 값과 단추만 보이고, 약관은 작은 링크로 열어 봅니다.

3.4.32026-11-12

한글을 쓰고 Enter 를 누르면 줄이 한 번만 바뀝니다.

  • 맥 한글 입력기에서 글자를 쓰다 Enter 를 누를 때 빈 줄이 하나 더 생기던 것을 바로잡았습니다.

3.4.22026-11-12

카카오와 애플로도 로그인합니다.

  • 하이퍼세븐 계정을 카카오·Apple·Google 가운데 편한 것으로 시작합니다.

3.4.12026-11-12

응원하기 아래에 서포터 혜택을 적었습니다.

  • 새 기능 먼저 받기 · 우선 답변 · 서포터 표시

3.4.02026-11-12

하이퍼 AI 를 더 쉽게, 더 정확하게 씁니다.

  • 내 API 키를 넣으면 바로 맞는 키인지 확인합니다. 키를 만드는 곳으로 가는 링크도 있습니다.
  • 로그인이나 키 넣기를 마치면 보내던 요청을 이어서 처리합니다.
  • 하이퍼 AI 맥스가 최신 모델로 더 똑똑하고 저렴해졌습니다.
  • 결제를 마치고 돌아오면 구독과 응원이 바로 반영됩니다.
  • 응원해 주신 분은 새 기능을 먼저 받습니다.

3.3.32026-11-12

응원하기가 잘 보입니다.

  • 메뉴 막대 오른쪽 ♥ 응원, 작업 창 아래 띠에서 바로 응원할 수 있습니다.
  • 응원해 주신 분께는 고맙다는 인사가 보입니다.

3.3.22026-11-12

하이퍼 AI 를 더 빨리 시작합니다.

  • 처음 쓸 때 확인 체크 없이 바로 키를 넣고 씁니다.

3.3.12026-11-11

구독과 응원, 두 가지로 간단해졌습니다.

  • 구독하기: 하이퍼 AI 연결이 켜집니다. 처음 7일은 무료입니다.
  • 응원하기: 앱은 그대로, 매달 또는 한 번 응원합니다.

3.3.02026-11-11

새 설치 파일입니다. 그동안 받은 기능이 처음부터 모두 들어 있습니다.

  • 하이퍼 AI 를 내 Anthropic API 키로 바로 씁니다.
  • 응원을 매달 또는 한 번으로 고를 수 있습니다.
  • 한글을 빠르게 쳐도 글자가 그대로 들어갑니다.

3.2.112026-11-11

응원을 매달 또는 한 번, 고르기 쉽게 바꿨습니다.

  • 매달 응원은 프로그램 사용료처럼 월 ₩3,900로 꾸준히 응원합니다.
  • 한 번 응원은 ₩6,900부터 금액을 골라 응원합니다.

3.2.102026-11-11

하이퍼 AI 를 내 Anthropic API 키로 바로 씁니다.

  • 로그인한 뒤 키를 한 번 넣으면, 다음부터는 로그인만 하면 됩니다.
  • 연결은 월 ₩6,900이고, 정식 결제를 열기 전까지는 무료입니다.

3.2.92026-11-11

한글 입력을 고쳤습니다.

  • 인텔 맥처럼 조금 느린 컴퓨터에서 빠르게 칠 때 글자가 빠지던 문제(“취소하고”가 “취하”로)를 고쳤습니다.

3.2.82026-11-11

처음 열면 작업 창과 하이퍼 AI 가 함께 열립니다.

  • 필요 없으면 닫으면 되고, 닫은 상태는 다음에도 그대로입니다.
  • 응원 창이 더 단순해졌습니다.

3.2.72026-11-11

하이퍼 AI 가 보고서를 더 반듯하게 씁니다.

  • 개조식 보고서(□ ○ -)에 새 절을 넣으면 문서의 기호와 줄 나눔을 그대로 따릅니다.
  • 하이퍼 AI 맥스는 맡긴 글을 다시 쓰지 않고 틀린 곳만 짚어 고쳐, 더 빠르고 적게 씁니다.

3.2.62026-11-11

AI 가 하이퍼 AI 로 새로 태어났습니다.

  • 라이트·일반·프로·맥스가 일을 나눠 맡습니다. 가벼운 일은 가볍게, 어려운 일은 위 단계로 넘깁니다.
  • 긴 글은 프로가 계획하고 일반이 써서, 같은 결과를 더 적은 비용으로 냅니다. 맥스는 바뀐 곳만 다시 확인합니다.
  • 내 API 키는 로그인한 뒤 한 번만 넣으면 다음부터 바로 씁니다.

3.2.52026-11-11

AI 도우미를 처음 쓰기가 쉬워졌습니다.

  • 처음 열어도 단계 이름(빠르게·보통·꼼꼼하게·최고)이 바로 보입니다.
  • 시작 안내가 깔끔해졌습니다. 내 API 키 칸과 단추가 한곳에 모였습니다.
  • 파일 메뉴의 새로 만들기가 HWP·XLSX·PPTX 형식 이름으로 맞춰졌습니다.

3.2.42026-11-11

AI 제안이 한눈에 읽힙니다.

  • 바뀌는 말만 줄을 긋고 새 말을 나란히 보여 드립니다. 넣을 표는 작은 표로 미리 보입니다.
  • 보고서를 발표로 만들면 날짜 줄은 표지에 들어가고, 표는 슬라이드를 넉넉히 채웁니다.
  • 위쪽 신호등이 천천히 숨 쉬며 지금 쓰는 도구를 알려 줍니다.
  • 창이 좁아도 도구 막대가 다음 줄로 이어져 모든 단추가 보입니다.
  • 화면 곳곳의 문장을 자연스럽게 다듬었습니다.

3.2.32026-11-10

AI 단계가 한눈에 보입니다.

  • 단계 목록에 중간·높은·가장 높은 지능이 보이고, 어느 요금에서 쓰는지 함께 나옵니다.
  • 응원해 주신 분께는 계정 단추에 작은 하트가 붙고, 맛보기를 바로 써 볼 수 있습니다.

3.2.22026-11-10

응원이 한눈에 보입니다.

  • 계정 창·AI 창·정보 창의 분홍 응원하기 단추로 바로 응원합니다.
  • 커피 한 잔이나 비트코인으로도 응원할 수 있습니다.
  • AI 제안이 잘 들어가거나 PDF를 만든 순간, 가끔 짧게 인사합니다.

3.2.12026-11-10

AI를 필요한 만큼 고릅니다.

  • 모든 편집 기능은 그대로 무료입니다. AI가 무엇을 하는지 미리 보기로 먼저 보여 줍니다.
  • 서포터 팩으로 후원하면 감사 선물로 AI 맛보기를 드립니다.
  • 일반·프로·맥스 중 필요한 지능을 고릅니다. 정식 요금은 곧 시작합니다.

3.2.02026-11-10

펜으로 첨삭하면 AI가 그대로 고칩니다.

  • 줄 긋기, 줄 긋고 고쳐 쓰기, ∨ 끼워 넣기·띄어 쓰기, ⌒ 붙여 쓰기 같은 교정 부호를 알아봅니다.
  • 여백에 적은 메모도 읽어 그 문단에 반영합니다.
  • 같은 낱말이 여러 곳에 있어도 표시한 자리만 고칩니다.
  • AI 도우미가 새 연결 방식으로 더 안정적으로 동작합니다.

3.1.32026-11-10

AI 도우미가 보고서를 한 번에 써 줍니다.

  • “사업 계획서 초안 써 줘”라고 하면 제목·목록·표·굵은 글씨까지 한 번에 넣습니다.
  • 절을 새로 쓰거나 다시 써 달라는 요청도 모양을 갖춰 들어갑니다.
  • 빈 문서에도 바로 쓰고, 표를 만들어 내용까지 채웁니다.

3.1.22026-11-10

한글 입력이 더 매끄러워졌습니다.

  • “추천”처럼 받침이 다음 글자로 넘어가는 낱말도 빠르게 쳐도 그대로 들어갑니다.
  • 오류·불편 알림은 기본으로 켜져 조용히 동작합니다. 처음 보낼 때 한 번만 짧게 알립니다.
  • AI 도우미 안내를 새로 다듬었습니다. 처음 한 번 다시 동의해 주세요.

3.1.12026-11-10

AI 도우미가 문서를 더 많이 직접 만들어 줍니다.

  • 빈 문서에도 바로 “소개 글 써 줘”, “표 만들어 줘”라고 하면 됩니다.
  • “표로 정리해 줘”라고 하면 내용을 채운 표를 만듭니다.
  • 문단 지우기, 문서 끝에 덧붙이기도 됩니다.
  • 초안은 바로 쓰고, 모르는 정보는 [회사명]처럼 빈칸으로 남깁니다.

3.1.02026-11-10

하이퍼세븐 계정으로 로그인하면 AI 도우미를 바로 씁니다.

  • 고성능 AI: 최신 Claude로 더 빠르고 정확하게, 긴 문서도 한 번에 — 오피스 AI 월 ₩9,900 (곧 시작).
  • 계정 하나로 하이퍼세븐 오피스와 캐드를 함께 씁니다.

3.0.02026-11-10

AI와 함께 쓰는 새로운 오피스. 빨간펜으로 표시하고 말로 시키면 AI가 고칠 곳을 제안합니다.

  • 빨간펜·형광펜 첨삭: 문서 위에 적고 “첨삭대로 고쳐 줘”. 인쇄되지 않는 별도 층입니다.
  • 말로 입력: AI 창의 마이크를 누르고 말하면 글이 됩니다.
  • AI 단계: 자동·빠르게·보통·꼼꼼하게·최고. 앱 기능은 단추와 단축키로 알려 줍니다.
  • 위쪽 신호등으로 글·셈·발표를 오가고, 발표에서 겹친 도형을 ⌥+클릭으로 고릅니다.
  • HWP 문서가 원본과 더 같게 보입니다. 없는 글꼴은 알려 드립니다.

2.0.52026-11-09

표 계산이 한글처럼 저절로 다시 계산되고, 손에 익은 동작이 훨씬 편해졌습니다.

  • 블록 합계·계산식이 칸을 고치면 따라 바뀝니다. 워드로 저장해도 계산식이 남습니다.
  • 엑셀에서 복사한 표를 표 칸에 붙이면 칸을 채웁니다.
  • 글자 색·형광펜 팔레트, 글자 크기 −/+ 단추와 목록, 표 크기 고르기가 생겼습니다.
  • 같은 파일은 한 번만 열리고, 맥 ⌘↑·⌘↓와 목록 Tab 수준이 익숙하게 동작합니다.
  • 오류와 불편한 순간을 글 내용 없이 알려 고칩니다(환경 설정에서 끌 수 있음).

2.0.42026-11-08

그림 넣기와 크기 맞추기가 훨씬 부드러워졌습니다.

  • 크기를 바꿀 때 미리 보여 주고, 손잡이가 커졌습니다.
  • 모서리를 끌면 가로·세로 비율이 그대로 유지됩니다.
  • 그림을 누른 채 바로 끌어 옮깁니다.
  • 화면 아래에 쪽 맞춤·폭 맞춤·확대 단추가 생겼습니다.
  • 인텔 맥용과 Microsoft Store(윈도우)에서도 받습니다.

2.0.32026-11-07

맥 앱이 애플 공증을 받았습니다. 내려받아 처음 열 때도 경고 없이 바로 열립니다.

  • 맥: 처음 열 때 나오던 '확인되지 않은 개발자' 경고와 '그래도 열기' 단계가 없어졌습니다.
  • 작업 창의 문단 왼쪽·오른쪽 여백에 음수도 넣을 수 있습니다. 문단을 본문 여백 밖으로 내밀 때 씁니다(문단 모양 창과 같습니다).
  • 윈도우: 새 버전 안내 창이 윈도우에 맞는 설치 방법을 알려 줍니다.

2.0.22026-11-06

한글 문서를 워드로 저장하면 문단 사이 간격까지 한글과 같게 나옵니다.

  • 워드(.docx)로 저장한 문서를 워드에서 열 때 문단 사이가 한글보다 좁아 보이던 것을 고쳤습니다.

2.0.12026-11-06

앱이 꺼져 있을 때 문서를 두 번 눌러 열면, 그 문서가 바로 열립니다.

  • 문서를 두 번 눌러 앱을 켜면 빈 문서만 뜨던 문제를 고쳤습니다 (맥 Finder·윈도우 탐색기·명령줄 모두).

2.0.02026-11-06

HyperSeven Office로 새롭게 나왔습니다. 한글·워드·엑셀·파워포인트·PDF를 한 앱에서 다루고, 윈도우판과 영어 화면, 명령 찾기가 더해졌습니다.

  • 윈도우 10·11(64비트) 지원: .exe를 실행하면 바로 설치되고, 한글 Windows 방식 단축키를 그대로 씁니다.
  • 영어 화면: 처음에는 운영체제 언어를 따르고, 환경 설정 › 보기 › 언어에서 바꿉니다.
  • 명령 찾기 ⌘K(윈도우 Ctrl+Shift+K): 이름이나 초성 몇 자로 모든 명령을 바로 실행합니다.
  • 문제 알리기: 도구 › 문제 알리기…에서 한 줄만 적어 보내면 됩니다. 문서 모양이 문제라면 글자를 지운 사본을 붙일 수 있고, 고쳐지면 앱이 알려 드립니다.
  • 쓰던 설정·단축키·최근 문서·자동 저장은 처음 실행할 때 그대로 옮겨 옵니다. AI 도우미 열쇠만 한 번 다시 넣어 주세요.
  • AI 에이전트용 명령줄과 MCP 이름이 hyperseven, 도구 이름이 office_*로 바뀌었습니다. 도구 › AI 연결 (MCP)에서 새 명령을 복사해 다시 연결해 주세요.
  • 새 아이콘과 새 홈페이지.
