# 세종

한글(HWP·HWPX)·워드·PDF·엑셀·파워포인트 문서를 한 앱에서 다루는 **맥용 무료 문서 편집기**입니다.
한글에서 쓰던 메뉴와 단축키가 그대로이고, AI 에이전트가 쓸 수 있는 명령줄·MCP 서버도 함께 들어 있습니다.

- 홈페이지·내려받기: https://dongyoun.github.io/sejong/
- 설치 파일: 이 저장소의 [Releases](../../releases)
- 문의·버그 알리기: [Issues](../../issues)

이 저장소에는 홈페이지와 설치 파일만 있습니다.

본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. 세종은 한글과컴퓨터와 관계가 없습니다.
