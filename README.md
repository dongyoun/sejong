# 하이퍼세븐 랩스 · HyperSeven Labs

글짓기부터 집짓기까지 — 문서를 쓰는 사람과 공간을 설계하는 사람을 위한 도구를 만듭니다.

- **하이퍼세븐 오피스**: 한글(HWP·HWPX)·워드·PDF·엑셀·파워포인트 문서를 한 앱에서 다루는 **맥·윈도우용 무료 문서 편집기**입니다. 한국어와 영어 화면이 있고, AI 에이전트가 쓸 수 있는 명령줄·MCP 서버도 함께 들어 있습니다.
- **하이퍼세븐 캐드**: 건축 설계 도구입니다. 개발 중입니다.

바로 가기:

- 홈페이지: https://hyperseven.pages.dev/
- 매뉴얼: https://hyperseven.pages.dev/manual
- 설치 파일: 이 저장소의 [Releases](../../releases)
- 문의·버그 알리기: [Issues](../../issues)

이 저장소에는 설치 파일과 홈페이지 사본만 있습니다. 앱이 새 판을 확인하는 안내문(latest.json)도 이 저장소의 GitHub Pages 에 함께 둡니다.

본 제품은 한글과컴퓨터의 한글 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다. 하이퍼세븐 오피스는 한글과컴퓨터와 관계가 없습니다.
