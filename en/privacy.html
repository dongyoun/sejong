HyperSeven Office

Privacy Policy

Effective November 10, 2026

At a glance

  • Your documents are opened, edited and saved on your computer. The app only sends document content anywhere when you use the AI assistant or send a problem report yourself, as described below.
  • There are no accounts, and nothing is collected for advertising or marketing. Errors and friction signals are sent automatically without any document text, used only to fix the app, and can be turned off in Preferences.

When the app connects to the internet

Checking for updates

When the app starts, and every 6 hours while it's open, it downloads one public file from the website (latest.json). This request carries no personal information or document content. Cloudflare and GitHub, which host the website, may process connection data such as your IP address, as with any web request. Update files are downloaded from GitHub. If you installed the app from the Microsoft Store, the Store keeps it up to date.

When the app starts, it also asks the website once whether HyperSeven account sign-in is available. This request carries no personal information or document content either.

AI assistant (only if you turn it on)

Only after you enter your own Anthropic API key and agree, each request you send — together with as much of the open document's text as it needs — goes to Anthropic, which handles it under Anthropic's privacy policy. Your API key is encrypted with your operating system's keychain on this computer and is never sent to HyperSeven. If you choose a model on your own computer, requests stay on your computer.

Problem reports (only when you send one)

When you send a report, it includes what you wrote plus the app version, operating system, recent error log, recent commands and a summary of the document's structure (no text). A copy of the document is attached only if you choose to, and only with its text scrambled.

Problem reports you send are stored in HyperSeven's report store (Cloudflare); only if it can't be reached does the app open a pre-filled GitHub issue instead.

Automatic error and friction reports (can be turned off)

After a few minutes of use the app tells you about this once; unless you turn it off, it sends a bundle once a day. It includes the app version, OS and language, error logs, document structure counts (sections, paragraphs, tables, objects — no text), recent command names, and friction signals (counts of things like searches in Find Command that found nothing, shortcuts that did nothing, commands undone right away, commands that weren't available, and file types that failed to open). Document text, file names and paths are never sent. You can see exactly what is sent, and turn it off, in Preferences › User › See what is sent.

This information is used only to fix the next version. IP addresses are not stored (a hashed value is kept for one hour only to prevent abuse).

HyperSeven CAD

HyperSeven CAD works the same way. At start it fetches one public file from the website (latest-cad.json) to check for a new version. Automatic error and friction reports are offered once — the first time you use the app, or right after something goes wrong — and are sent only if you agree. They contain the version, OS, recent command names, error messages (with paths removed), counts of friction signals and the number of elements in the drawing; drawing content, file names and paths are never sent. See what is sent and turn it off in Settings › General › Fix it together. Screenshots from Feedback (⌘⇧F) stay on your computer.

What stays on your computer

Settings, the recent documents list, autosave copies, the error log and fonts you added are stored only in the app's data folder on your computer. You can delete that folder yourself, including after uninstalling the app.

If you installed from the Microsoft Store

Downloads, updates and ratings in the Store are covered by Microsoft's privacy statement.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
