개인정보 처리방침

시행일 2026년 11월 7일

한눈에

  • 문서는 이 컴퓨터에서 열고, 고치고, 저장합니다. 앱이 문서를 서버로 보내는 일은 아래의 AI 도우미와 문제 알리기를 사용자가 직접 쓸 때뿐입니다.
  • 회원 가입이 없고, 광고나 사용 분석을 위한 정보를 모으지 않습니다.

인터넷에 연결하는 경우

새 버전 확인

앱을 켤 때와 켜 둔 동안 6시간마다 홈페이지의 공개 안내 파일(latest.json) 하나를 받습니다. 이 요청에는 개인 정보나 문서 내용이 담기지 않습니다. 홈페이지를 제공하는 Cloudflare와 GitHub는 일반적인 웹 요청처럼 IP 주소 같은 접속 기록을 처리할 수 있습니다. 새 버전 파일은 GitHub에서 받습니다. Microsoft Store로 설치한 앱은 새 버전을 스토어가 바꿔 줍니다.

AI 도우미 (사용자가 켤 때만)

사용자가 Anthropic API 키를 넣고 동의한 경우에만, 요청을 보낼 때 그 요청과 지금 문서의 글(필요한 만큼)을 Anthropic으로 보냅니다. 보낸 정보는 Anthropic의 개인정보 처리방침에 따라 처리됩니다. API 키는 이 컴퓨터의 운영체제 열쇠고리로 암호화해 보관하고, HyperSeven으로 보내지 않습니다. ‘내 컴퓨터 모델’을 고르면 요청은 이 컴퓨터 안에서만 처리됩니다.

문제 알리기 (사용자가 보낼 때만)

사용자가 보낼 때, 적은 내용과 함께 앱 버전·운영체제·최근 오류 기록·최근 명령·문서 구조 요약(글 없음)을 보냅니다. 문서 사본은 사용자가 붙이기로 고른 경우에만, 글자를 지운 사본으로 보냅니다. 지금은 내용을 미리 채운 GitHub 이슈 화면이 열리며, 사용자가 올린 내용은 GitHub에 공개됩니다.

오류가 났을 때 자동 알림에 동의하면, 그다음부터는 문서 글 없이 오류 정보만 보냅니다. 동의하지 않으면 보내지 않습니다.

이 컴퓨터에 저장하는 것

설정, 최근 문서 목록, 자동 저장 사본, 오류 기록, 추가한 글꼴은 이 컴퓨터의 앱 데이터 폴더에만 저장됩니다. 앱을 지운 뒤에도 남는 이 폴더는 직접 지울 수 있습니다.

Microsoft Store로 설치한 경우

스토어에서의 내려받기·업데이트·평가에는 Microsoft의 개인정보 처리방침이 적용됩니다.
