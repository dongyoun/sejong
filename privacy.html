시행일 2026년 11월 21일

한눈에

이 방침은 사업자 히스테리시스(대표 신인수, 이하 “운영자”)가 ‘하이퍼세븐’이라는 이름으로 제공하는 하이퍼세븐 오피스·하이퍼세븐 캐드 앱과 하이퍼세븐 계정, 응원에 적용됩니다.

  • 문서는 이 컴퓨터에서 열고, 고치고, 저장합니다. 앱이 문서를 서버로 보내는 일은 아래의 AI 도우미와 문제 알리기를 사용자가 직접 쓸 때뿐입니다.
  • 앱은 회원 가입 없이 씁니다. 하이퍼세븐 계정은 AI를 쓰려는 사람만 만드는 선택이고(아래), 광고나 마케팅을 위한 정보는 모으지 않습니다. 오류와 불편 신호는 문서 글 없이 자동으로 보내 고치는 데만 쓰며, 환경 설정에서 끌 수 있습니다.

인터넷에 연결하는 경우

새 버전 확인

앱을 켤 때와 켜 둔 동안 6시간마다 홈페이지의 공개 안내 파일(latest.json) 하나를 받습니다. 이 요청에는 개인 정보나 문서 내용이 담기지 않으며, 요청 횟수는 날짜별 합계로만 셉니다(아래). 홈페이지를 제공하는 Cloudflare와 GitHub는 일반적인 웹 요청처럼 IP 주소 같은 접속 기록을 처리할 수 있습니다. 설치 파일과 새 버전 파일은 GitHub(GitHub, Inc., 미국)에서 받으며, 이때의 접속 기록은 GitHub의 개인정보 처리방침에 따라 처리됩니다. Microsoft Store로 설치한 앱은 새 버전을 스토어가 바꿔 줍니다.

앱을 켤 때 홈페이지에 하이퍼세븐 계정 로그인을 쓸 수 있는지 한 번 묻습니다. 이 요청에도 개인 정보나 문서 내용은 담기지 않습니다.

AI 도우미 (사용자가 켤 때만)

내 Anthropic API 키로 쓰고 동의한 경우에만, 요청을 보낼 때 그 요청과 지금 문서의 글(필요한 만큼)을 Anthropic으로 보냅니다. 보낸 정보는 Anthropic의 개인정보 처리방침에 따라 처리됩니다. API 키는 이 컴퓨터의 운영체제 열쇠고리로 암호화해 보관하고, HyperSeven으로 보내지 않습니다. ‘내 컴퓨터 모델’을 고르면 요청은 이 컴퓨터 안에서만 처리됩니다.

문제 알리기 (사용자가 보낼 때만)

사용자가 보낼 때, 적은 내용과 함께 앱 버전·운영체제·최근 오류 기록·최근 명령·최근 키 조작 순서(Enter·지우기 같은 키 종류와 시각 차이 — 무슨 글자를 쳤는지는 없음)·문서 구조 요약(글 없음)을 보냅니다. 문서 사본은 사용자가 붙이기로 고른 경우에만, 글자를 지운 사본으로 보냅니다.

사용자가 보낸 문제 알리기는 HyperSeven의 신고 저장소(Cloudflare)에 쌓이고, 받는 곳에 닿지 못할 때만 내용을 채운 GitHub 이슈 화면을 엽니다.

오류·불편 신호 자동 알림 (끌 수 있음)

기본으로 켜져 있고, 처음 보낼 때 한 번 짧게 알립니다. 오류는 생긴 때에, 불편 신호는 하루 한 번 묶어 보냅니다. 보내는 것은 앱 버전·운영체제·언어, 오류 기록, 문서 구조 수(구역·문단·표·개체 — 글 없음), 최근 명령 이름, 그리고 불편 신호(명령 찾기에서 찾지 못한 말, 아무 명령도 없던 단축키, 곧바로 되돌린 명령, 쓸 수 없었던 명령, 열지 못한 파일 형식 등의 종류별 횟수)입니다. 문서 글·파일 이름·경로는 보내지 않습니다. 실제로 보내는 내용은 환경 설정 › 사용자의 [보내는 내용 보기]에서 그대로 볼 수 있고, 같은 곳에서 끕니다.

받은 정보는 다음 버전을 고치는 데만 쓰고, IP 주소는 저장하지 않습니다(너무 잦은 요청을 막는 데에만 한 시간 동안 섞은 값으로 씁니다). 자동 알림과 문제 알리기(적은 내용·연락처·붙인 사본·화면 그림 포함)는 받은 날부터 1년 보관한 뒤 지웁니다.

하이퍼세븐 캐드

하이퍼세븐 캐드도 같은 방식입니다. 시작할 때 홈페이지의 공개 안내 파일(latest-cad.json) 하나를 받아 새 판을 확인합니다. 오류·불편 신호 자동 알림은 기본으로 켜져 있습니다. 처음 실제로 보낼 때 화면 오른쪽 아래에 한 줄로 알리고(보내는 내용 보기·끄기), 끈 경우에는 보내지 않습니다. 보내는 것은 판·운영체제·최근 명령 이름·오류 글(경로는 지움)·불편 신호의 종류별 횟수와 도면의 요소 수뿐이고, 도면 내용·파일 이름·경로는 보내지 않습니다. 설정 › 일반 › 함께 고치기에서 보내는 내용을 보고 끕니다.

캐드의 문제 알리기(⌘⇧F·도움말 › 문제 알리기…, 사용자가 [보내기]를 누를 때만)는 적은 내용과 함께 판·운영체제·작업 공간·탭 종류·도구·진행 중이던 명령 이름·최근 명령 이름·최근 메시지 몇 줄(경로·메일 주소처럼 보이는 낱말은 지움)·이번 실행의 오류(5개까지)를 보내고, 연락처는 적은 경우에만 보냅니다. 지금 화면의 그림이 기본으로 함께 가며, 보내기 전에 미리 보고 뺄 수 있습니다. 그림에는 그때 화면에 보이던 도면이 담길 수 있습니다. 도면 파일은 보내지 않습니다. 보낸 신고의 사본(적은 글·함께 간 정보·그림)은 이 컴퓨터(~/.supercad/feedback)에도 남습니다. 앱은 시작할 때 이 컴퓨터에서 보낸 신고 번호(최근 50개)만 보내 고쳐졌는지 묻고, 고쳐진 것이 있으면 한 번 알립니다.

대지 지도·주소 조회 (캐드, 로그인한 사람만) — 대지 카드와 지도에서 주소를 찾거나 필지를 누르면, 지도 화면의 범위·찾는 주소·필지 번호를 운영자 서버를 거쳐 국토교통부 공간정보 오픈플랫폼(브이월드)에 보내 지도·필지 경계·용도지역을 받습니다. 운영자는 주소·좌표·필지 번호를 저장하지 않고, 계정 번호별 하루 이용 횟수만 셉니다.

설계지침서·과업 자료 첨부 (캐드) — 파일을 붙이면 앱이 이 컴퓨터에서 글만 뽑고(원본 파일은 보내지 않음), 전화번호·메일·주민등록번호 꼴은 기본으로 가립니다. 하이퍼 AI가 필요한 대목만 읽어 그 글을 AI 요청에 싣습니다. 내 Anthropic API 키로 쓰는 경우 요청은 앱이 Anthropic에 직접 보내며 운영자 서버를 거치지 않고, 운영자는 받거나 저장하지 않습니다.

AI 렌더 (캐드, 사용자가 켤 때만) — 지금 화면의 그림과 설명을 사용자가 고른 렌더 서비스(이 컴퓨터의 ComfyUI, Stability AI, OpenAI 또는 사용자가 적은 주소)에 사용자의 키로 직접 보냅니다. 사람 얼굴은 보내기 직전에 가립니다. 운영자 서버를 거치지 않으며, 보낸 정보는 그 서비스의 방침에 따라 처리됩니다.

방문·새 판 확인 횟수

홈페이지와 앱이 얼마나 쓰이는지 알려고 날짜별 횟수만 셉니다. 쿠키를 쓰지 않고, IP 주소나 사람·기기를 알아볼 수 있는 값은 저장하지 않습니다.

  • 홈페이지 — 쪽을 열면 그 쪽의 주소와, 다른 사이트에서 들어왔는지 여부를 그날의 합계에 더합니다.
  • 새 판 확인 — 앱이 새 판 안내 파일(latest.json·latest-cad.json)을 받을 때, 앱이 보내는 사용자 에이전트에서 읽은 앱의 판과 운영체제(맥·윈도우)를 그날의 합계에 더합니다.

합계는 Cloudflare(위탁)의 데이터베이스에 남습니다. 사람을 알아볼 수 없는 통계라 따로 지우는 기간을 두지 않습니다.

하이퍼세븐 계정 (가입한 사람만)

계정은 선택입니다. 앱의 편집 기능은 계정 없이 모두 씁니다. 계정을 만든 사람에 대해서만 아래 정보를 다룹니다.

받는 것

  • 로그인 공급자(Apple·Google·카카오)가 알려 주는 이름(또는 닉네임), 메일, 공급자 안의 고유 번호. 카카오에서는 이용자가 동의한 항목(닉네임)만 받습니다. Apple의 ‘메일 가리기’를 쓰면 중계 주소를 받습니다.
  • 로그인한 기기의 이름(예: “Mac · 이름”, 윈도우는 컴퓨터 이름). 기기 토큰은 해시만 남깁니다.
  • 사용 기록: 운영자 서버를 거치는 AI 요청의 앱·모델·토큰 수·원가·시각, 대지 지도를 연 횟수(하루 단위). 요청 글과 응답 글은 저장하지 않습니다.

만 14세 미만 아동

만 14세 미만은 하이퍼세븐 계정을 만들 수 없으며, 운영자는 만 14세 미만 아동의 개인정보를 받지 않습니다. 만 14세 미만의 계정임을 알게 되면 그 정보를 지체 없이 지웁니다. 계정 없이 쓰는 앱의 편집 기능은 나이와 관계없이 씁니다.

쓰는 곳

로그인, AI·지도 기능 제공, 너무 잦은 요청과 부정 이용 막기.

보관 기간

계정을 지우면 이름·메일·로그인 수단·기기 토큰은 바로 지웁니다. 사용 기록은 계정 번호와 함께만 남고, 1년이 지나면 지웁니다.

파기

보관 기간이 끝났거나 쓸 목적이 없어진 정보는 데이터베이스에서 지워 되살릴 수 없게 합니다. 종이로 남기는 개인정보는 없습니다.

처리를 맡기는 곳 (위탁)과 국외 이전

계정·AI 기능을 쓸 때 그때마다 인터넷(암호화된 연결)으로 아래 회사에 보내지며, 쓰지 않으면 보내지 않습니다. 거부하려면 계정·AI 기능을 쓰지 않으면 되고, 이 경우 해당 기능만 쓸 수 없고 앱의 편집 기능은 그대로 씁니다.

  • Cloudflare, Inc. (미국 등 Cloudflare 네트워크, 처리방침·연락처) — 계정 정보, 사용 기록, 자동 알림·문제 알리기 — 서버·데이터베이스 운영 — 위 보관 기간
  • Anthropic, PBC (미국, 처리방침·연락처) — 운영자 서버를 거치는 AI 요청의 글, 필요한 만큼의 문서·첨부 내용 — AI 응답 만들기 — Anthropic 방침에 따름(학습에 쓰지 않는 API). 내 API 키로 쓰는 경우는 앱이 이용자의 계약으로 Anthropic에 직접 보냅니다.

제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다.

이용자의 권리

계정 정보를 보거나 고치거나 지우도록 요청할 수 있습니다. 앱의 ‘계정 지우기’로 바로 지우거나, 이메일로 요청합니다.

안전하게 지키는 방법

모든 전송은 암호화된 연결(HTTPS)로 하고, 기기 토큰은 해시로만 남기며, 데이터베이스에 들어갈 수 있는 사람을 대표 한 사람으로 줄였습니다. 카드 번호 같은 결제 정보는 받지 않습니다. 홈페이지와 앱은 광고·추적용 쿠키를 쓰지 않습니다.

응원 (응원한 사람만)

  • Buy Me a Coffee — 응원한 사람이 Buy Me a Coffee에 적은 이름(또는 별명)·메일·메시지와 금액을 Buy Me a Coffee가 운영자에게 알려 줍니다. 결제는 Buy Me a Coffee와 그 결제 대행사가 처리하며(처리방침), 카드 번호 같은 결제 정보는 받지 않습니다.
  • 카카오페이 — 보낸 분의 이름(카카오페이가 받는 사람에게 보여 주는 대로)과 금액, 보낸 때, 남긴 말을 카카오페이가 운영자에게 보여 줍니다. 송금은 카카오페이가 처리하며, 계좌·카드 같은 결제 정보는 받지 않습니다.
  • 비트코인 — 블록체인에 공개된 보낸 주소와 금액 밖에는 받는 정보가 없습니다.

이 컴퓨터에 저장하는 것

설정, 최근 문서 목록, 자동 저장 사본, 오류 기록, 추가한 글꼴은 이 컴퓨터의 앱 데이터 폴더에만 저장됩니다. 앱을 지운 뒤에도 남는 이 폴더는 직접 지울 수 있습니다.
