개인정보 처리방침

시행일 2026년 11월 10일

한눈에

  • 문서는 이 컴퓨터에서 열고, 고치고, 저장합니다. 앱이 문서를 서버로 보내는 일은 아래의 AI 도우미와 문제 알리기를 사용자가 직접 쓸 때뿐입니다.
  • 앱은 회원 가입 없이 씁니다. 하이퍼세븐 계정은 AI나 구독을 쓰려는 사람만 만드는 선택이고(아래), 광고나 마케팅을 위한 정보는 모으지 않습니다. 오류와 불편 신호는 문서 글 없이 자동으로 보내 고치는 데만 쓰며, 환경 설정에서 끌 수 있습니다.

인터넷에 연결하는 경우

새 버전 확인

앱을 켤 때와 켜 둔 동안 6시간마다 홈페이지의 공개 안내 파일(latest.json) 하나를 받습니다. 이 요청에는 개인 정보나 문서 내용이 담기지 않습니다. 홈페이지를 제공하는 Cloudflare와 GitHub는 일반적인 웹 요청처럼 IP 주소 같은 접속 기록을 처리할 수 있습니다. 새 버전 파일은 GitHub에서 받습니다. Microsoft Store로 설치한 앱은 새 버전을 스토어가 바꿔 줍니다.

앱을 켤 때 홈페이지에 하이퍼세븐 계정 로그인을 쓸 수 있는지 한 번 묻습니다. 이 요청에도 개인 정보나 문서 내용은 담기지 않습니다.

AI 도우미 (사용자가 켤 때만)

AI 구독(아래)이나 내 Anthropic API 키로 쓰고 동의한 경우에만, 요청을 보낼 때 그 요청과 지금 문서의 글(필요한 만큼)을 Anthropic으로 보냅니다. 보낸 정보는 Anthropic의 개인정보 처리방침에 따라 처리됩니다. API 키는 이 컴퓨터의 운영체제 열쇠고리로 암호화해 보관하고, HyperSeven으로 보내지 않습니다. ‘내 컴퓨터 모델’을 고르면 요청은 이 컴퓨터 안에서만 처리됩니다.

문제 알리기 (사용자가 보낼 때만)

사용자가 보낼 때, 적은 내용과 함께 앱 버전·운영체제·최근 오류 기록·최근 명령·문서 구조 요약(글 없음)을 보냅니다. 문서 사본은 사용자가 붙이기로 고른 경우에만, 글자를 지운 사본으로 보냅니다.

사용자가 보낸 문제 알리기는 HyperSeven의 신고 저장소(Cloudflare)에 쌓이고, 받는 곳에 닿지 못할 때만 내용을 채운 GitHub 이슈 화면을 엽니다.

오류·불편 신호 자동 알림 (끌 수 있음)

기본으로 켜져 있고, 처음 보낼 때 한 번 짧게 알립니다. 오류는 생긴 때에, 불편 신호는 하루 한 번 묶어 보냅니다. 보내는 것은 앱 버전·운영체제·언어, 오류 기록, 문서 구조 수(구역·문단·표·개체 — 글 없음), 최근 명령 이름, 그리고 불편 신호(명령 찾기에서 찾지 못한 말, 아무 명령도 없던 단축키, 곧바로 되돌린 명령, 쓸 수 없었던 명령, 열지 못한 파일 형식 등의 종류별 횟수)입니다. 문서 글·파일 이름·경로는 보내지 않습니다. 실제로 보내는 내용은 환경 설정 › 사용자의 [보내는 내용 보기]에서 그대로 볼 수 있고, 같은 곳에서 끕니다.

받은 정보는 다음 버전을 고치는 데만 쓰고, IP 주소는 저장하지 않습니다(너무 잦은 요청을 막는 데에만 한 시간 동안 섞은 값으로 씁니다).

하이퍼세븐 캐드

하이퍼세븐 캐드도 같은 방식입니다. 시작할 때 홈페이지의 공개 안내 파일(latest-cad.json) 하나를 받아 새 판을 확인합니다. 오류·불편 신호 자동 알림은 기본으로 켜져 있습니다. 처음 실제로 보낼 때 화면 오른쪽 아래에 한 줄로 알리고(보내는 내용 보기·끄기), 끈 경우에는 보내지 않습니다. 보내는 것은 판·운영체제·최근 명령 이름·오류 글(경로는 지움)·불편 신호의 종류별 횟수와 도면의 요소 수뿐이고, 도면 내용·파일 이름·경로는 보내지 않습니다. 설정 › 일반 › 함께 고치기에서 보내는 내용을 보고 끕니다. 불편 신고(⌘⇧F)의 화면 그림은 이 컴퓨터에만 남습니다.

하이퍼세븐 계정과 구독 (가입한 사람만)

계정은 선택입니다. 앱의 편집 기능은 계정 없이 모두 씁니다. 계정을 만들거나 AI를 구독한 사람에 대해서만 아래 정보를 다룹니다.

받는 것

  • 로그인 공급자(Apple·Google)가 알려 주는 이름, 메일, 공급자 안의 고유 번호. Apple의 ‘메일 가리기’를 쓰면 중계 주소를 받습니다.
  • 로그인한 기기의 이름(예: “Mac · 이름”). 기기 토큰은 해시만 남깁니다.
  • 구독 기록: 구독한 앱, 상태, 결제 기간, 결제 대행사의 구독·고객 번호.
  • AI 사용 기록: 앱, 모델, 토큰 수, 원가, 시각 (공정 사용 한도를 세는 데 씁니다). 요청 글과 응답 글은 저장하지 않습니다.
  • 카드 번호 같은 결제 정보는 받지 않습니다. 결제는 Paddle이 처리합니다.

쓰는 곳

로그인, 구독 확인과 사용 한도 계산, 환불, AI 기능 제공, 부정 이용 막기.

보관 기간

계정을 지우면 이름·메일·로그인 수단·기기 토큰은 바로 지웁니다. 구독·사용 기록은 전자상거래법이 정한 기간(대금 결제와 재화 공급 기록 5년, 소비자 불만·분쟁 기록 3년) 동안 계정 번호와 함께만 보관한 뒤 지웁니다.

처리를 맡기는 곳과 국외 이전

계정이나 구독을 쓸 때 인터넷으로 아래 회사에 보내지며, 쓰지 않으면 보내지 않습니다.

  • Cloudflare, Inc. (미국 등 Cloudflare 네트워크) — 계정 정보, 구독·사용 기록 — 서버·데이터베이스 운영 — 위 보관 기간
  • Paddle.com Market Ltd (영국) — 이용자가 Paddle 결제 화면에 직접 넣는 결제 정보, 계정 번호, 구독한 앱 — 정기 결제·영수증·세금·환불·구독 관리(판매자) — Paddle 방침에 따름
  • Anthropic, PBC (미국) — 고성능 AI의 요청 글과 필요한 만큼의 문서 내용 — AI 응답 만들기 — Anthropic 방침에 따름 (학습에 쓰지 않는 API)

이용자의 권리

계정 정보를 보거나 고치거나 지우도록 요청할 수 있습니다. 앱의 ‘계정 지우기’로 바로 지우거나, 이메일로 요청합니다.
